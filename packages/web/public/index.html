        Designed for anonymous use

        Disposable does not
        mean careless.

        The dangerous operations are deliberately kept away from the public HTTP service and bounded at multiple layers.

        Credential boundary

        The public API never receives the Zerops token. Only the private controller can create or delete infrastructure.

        Hard lifetime

        Claimed trials expire after 30 minutes. Idle pool projects rotate, and an orphan sweep catches interrupted imports.

        Guarded deletion

        Deletion requires an exact recorded project ID and a fresh ownership-tag check. Names and wildcard matching are never used.

        For maintainers

        One manifest opens the door.

        Describe the app, its managed services, entry port and proof checks. OpenTry applies strict ceilings before rendering a Zerops import.
