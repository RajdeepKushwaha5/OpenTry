      + Features +

      Real infrastructure, not a sandbox.

      Every trial is a genuine isolated Zerops project — verified before you get it, destroyed when you are done.

      Verified before handover.

      A trial is only released once its database is reachable and the page actually renders. A green deploy is not proof that anything works.

      Destroyed automatically.

      A 30-minute TTL, then a reaper deletes the whole project — containers, database, storage, routes. Nothing is left running.

      Run it yourself.

      Everything OpenTry does, you can run yourself. Validate a catalog manifest offline in milliseconds, then provision a real trial, verify it and destroy it — against your own Zerops account.

      ↓ Validate a catalog manifest offline
      npm run catalog:check
      ⌘ Provision, verify and destroy a real trial
      npm run gonogo -- --app n8n
      ✦ Nothing to install, nothing to clean up.

      One command deploys the whole control plane — no zcli, no Docker, no CI. Adding an app to the catalog is a single YAML file.
